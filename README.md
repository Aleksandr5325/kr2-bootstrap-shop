# MellShop на Bootstrap

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Дисциплина: «Фронтенд и бэкенд разработка».

## Описание

MellShop — магазин мягких игрушек: герои игр, мемов и мультфильмов и классические мягкие зверята. Это отдельная реализация той же предметной области, что и в КР №1, но интерфейс построен на CSS-фреймворке Bootstrap: сетка, навигация, карточки, формы, модальное окно и другие компоненты.

На сайте пять страниц: главная, каталог с фильтрами, страница товара, форма заявки и контакты.

## Подключение Bootstrap

В проекте Bootstrap подключён **локально**, без CDN. Файлы фреймворка скачаны с официального сайта (https://getbootstrap.com/docs/5.3/getting-started/download/, вариант «Compiled CSS and JS») и размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css` — стили Bootstrap;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JavaScript Bootstrap вместе с Popper (мобильное меню, выпадающий список, модальное окно, accordion, вкладки, карусель).

Рядом лежат `.map`-файлы (source maps): с ними DevTools показывает исходный код Bootstrap и не выдаёт предупреждений.

Собственный файл `css/custom.css` подключается **после** Bootstrap, чтобы его правила могли переопределять стили фреймворка:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
```

## Как посмотреть проект

- Онлайн: открыть ссылку GitHub Pages выше.
- Локально: скачать репозиторий (`git clone https://github.com/Aleksandr5325/kr2-bootstrap-shop.git`) и открыть `index.html` в браузере. Интернет не нужен: Bootstrap лежит в проекте (из сети загружается только шрифт Nunito, без него используется системный шрифт).

Что проверить:

- меню одинаковое на всех страницах, текущий пункт подсвечен, меню закреплено сверху при прокрутке;
- на узком экране (DevTools, 375px) меню сворачивается в кнопку и раскрывается;
- на главной — карусель (стрелки и точки), карточки популярных товаров;
- в каталоге — панель фильтров, 7 карточек, «Заказать» открывает модальное окно, «Подробнее» у бенгальского кота ведёт на страницу товара;
- на странице товара — вкладки «Характеристики / Описание / Доставка и оплата» и раскрывающиеся частые вопросы;
- на странице заявки — браузер не даёт отправить форму с пустыми обязательными полями;
- карточки перестраиваются: 1 в ряд на телефоне, 2 на планшете, 3 на компьютере.

## Реализованные компоненты Bootstrap

- `container`, `row`, `col-*`, `g-*` — адаптивная сетка всех страниц;
- `navbar` — единая навигация с мобильным меню, выпадающим списком и закреплением `sticky-top`;
- `card` — карточки товаров, контейнер формы заявки, блоки на странице контактов;
- `btn` — кнопки действий (`btn-primary`, `btn-outline-primary`, `btn-outline-secondary`, `btn-secondary`);
- `badge` — метки товаров «Новинка», «Хит», «Скидка»;
- `alert` — сообщения в каталоге, на странице товара, в форме заявки и на странице контактов;
- `modal` — окно быстрой заявки в каталоге;
- `form-control`, `form-select`, `input-group`, `form-check` — форма заявки, окно быстрой заявки и фильтры каталога;
- `accordion` — частые вопросы на странице товара;
- `carousel` — слайдер с игрушками на главной;
- `nav-tabs` (tabs) — вкладки на странице товара;
- `pagination` — постраничная навигация каталога;
- `breadcrumb` — хлебные крошки на страницах товара и контактов;
- `list-group` — список контактов;
- `table` — таблица характеристик товара.

## Самостоятельные доработки

Сверх пошаговых методических указаний в проекте сделано:

1. **Локальное подключение Bootstrap** без CDN — папка `vendor/bootstrap/`, способ подключения описан выше.
2. **Своя тема магазина.** Вместо учебных «Товар 1/2/3» — магазин мягких игрушек MellShop: 7 товаров с фотографиями, категориями, описаниями и ценами.
3. **Новая страница `contacts.html`** — контакты через `list-group`, карточка с призывом оформить заявку; пункт «Контакты» добавлен в меню всех страниц.
4. **Улучшенный каталог.** Панель фильтров (категории через `form-check`, цена «от/до» через `input-group`, сортировка через `form-select`), карточки с фото (`card-img-top`), категорией, бейджами и зачёркнутой старой ценой у товаров со скидкой, пагинация.
5. **Подробная страница товара.** Настоящее фото, вкладки «Характеристики / Описание / Доставка и оплата», таблица из 8 характеристик с подписью `caption`, три частых вопроса в `accordion`.
6. **Улучшенная форма заявки.** Выбор игрушки из списка (обязательное поле), способ доставки (радиокнопки `form-check`), телефон с префиксом «+7», `name` у всех полей; в окне быстрой заявки кнопка «Отправить» связана с формой атрибутом `form`.
7. **Дополнительные компоненты:** `carousel`, `nav-tabs`, `pagination`, `list-group`, `breadcrumb`.
8. **Фирменный стиль через `custom.css`.** Палитра MellShop (фиолетовый и тёплый кремовый, как в КР №1) задана через CSS-переменные Bootstrap (`--bs-primary`, `--bs-link-color`, `--bs-light-rgb`) и переменные компонентов (`--bs-btn-bg`, `--bs-pagination-active-bg` и др.), шрифт Nunito, увеличенные скругления, «подъём» карточек при наведении. Контраст текста и фона — не ниже 4,5:1.
9. **Адаптивность.** Проверены ширины 375, 768, 1024 и 1440 px: нет горизонтальной прокрутки, карточки перестраиваются, меню сворачивается; закреплённое меню и `scroll-margin-top`, чтобы якорь «Популярное» не прятался под меню.
10. **Публикация на GitHub Pages** и подробный README.
