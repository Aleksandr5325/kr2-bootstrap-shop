Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Проект представляет собой учебную версию сайта интернет-магазина или каталога товаров, разработанную с использованием Bootstrap.

- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных товаров;
- подвал страницы.

## Используемый фреймворк

Bootstrap 5.3.8.

## Подключение Bootstrap

В проекте Bootstrap подключён **локально**, без CDN. Файлы фреймворка скачаны с официального сайта (https://getbootstrap.com/docs/5.3/getting-started/download/, вариант «Compiled CSS and JS») и размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css` — стили Bootstrap;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JavaScript Bootstrap вместе с Popper (мобильное меню, выпадающий список, модальное окно, accordion).

Рядом лежат `.map`-файлы (source maps): с ними DevTools показывает исходный код Bootstrap и не выдаёт предупреждений.

Собственный файл `css/custom.css` подключается **после** Bootstrap, чтобы его правила могли переопределять стили фреймворка.

## Используемые компоненты Bootstrap

- `navbar` — единая навигация на всех страницах, с мобильным меню и выпадающим списком;
- `card` — карточки товаров в каталоге и контейнер формы заявки;
- `btn` — кнопки действий (`btn-primary`, `btn-outline-primary`, `btn-outline-secondary`);
- `badge` — метки товаров «Новинка», «Хит», «Скидка»;
- `alert` — информационные сообщения в каталоге, на странице товара и в форме заявки;
- `modal` — окно быстрой заявки в каталоге;
- `breadcrumb` — хлебные крошки на странице товара;
- `table` — таблица характеристик товара;
- `form-control`, `form-select`, `input-group`, `form-check` — форма заявки;
- `accordion` — частые вопросы на странице товара.
